### Workshop Overview

At **LA Tech Week 2026**, Google for Startups and Google for Developers hosted hands-on codelab tracks for enterprise founders, engineers, and technical leaders. Alongside fellow Google Developer Expert **Kiruthika Subramani**, I co-instructed two interactive technical workshops detailing how to build production-grade agentic architectures with Google Cloud and the **Model Context Protocol (MCP)**.

---

### Workshop 1: Location Intelligence ADK Agent with MCP Servers

- **Interactive Presentation & Teleprompter**: [Location Intelligence Deck](https://rabimba.github.io/GDE-ML-Artifacts/Location-Intelligence-ADK-MCP-Workshop/index.html)
- **Official Google Codelab**: [`adk-mcp-bigquery-maps`](https://codelabs.developers.google.com/adk-mcp-bigquery-maps)
- **Core Technologies**: Google Agent Development Kit (ADK), BigQuery Geospatial Data, Google Maps Grounding Lite MCP, Gemini 2.5 Flash

#### Architectural Focus
- **Agent Development Kit (ADK) Core**: Structuring autonomous agents with schema-enforced tool interfaces, state persistence, and error-recovery loops.
- **BigQuery MCP Integration**: Bridging spatial data warehouses with natural language queries—enabling dynamic SQL generation, bounding box filtering, and spatial joins over enterprise logistics tables without manual query plumbing.
- **Google Maps Grounding Lite MCP**: Validating place details, computing multi-modal travel times, and grounding model answers against live physical coordinates.
- **Production Guardrails**: Rate-limiting spatial queries, handling disconnected MCP sessions, and sanitizing agent reasoning steps.

---

### Workshop 2: Command & Control: Gemini, MCP & Agentic CLI

- **Interactive Presentation & Teleprompter**: [Command & Control Deck](https://rabimba.github.io/GDE-ML-Artifacts/Command-and-Control-Gemini-MCP-Workshop/index.html)
- **Official Google Codelab**: [`gemini-mcp-agy`](https://codelabs.developers.google.com/gemini-mcp-agy)
- **Core Technologies**: Antigravity CLI (`agy`), Developer Knowledge MCP, Agent Skills, Nano Banana 2 Image Gen, Google Cloud Run

#### Architectural Focus
- **Headless Agent Orchestration**: Driving terminal-first agentic developer loops with Antigravity CLI (`agy`), managing multi-step project scaffolding and debugging sessions.
- **Developer Knowledge MCP**: Exposing local codebase indexing, symbol trees, and architecture specs to agent runtimes without manual context dumping.
- **Multimodal Generation & Deployment**: Chaining multimodal synthesis via Nano Banana 2 for visual assets directly into automated container packaging and deployment to Google Cloud Run.
- **Composable Agent Skills**: Packaging reusable capability modules across teams to enforce testing, security, and deployment standards across agent prompts.
